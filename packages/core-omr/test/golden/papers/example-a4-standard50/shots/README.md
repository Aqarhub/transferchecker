# أين تعيش اللقطات

هذا المجلد فارغ عمداً، **والبايتات ليست في المستودع**.

لقطة PGM بدقة 1440×2560 حجمها 3.7 ميغابايت، وثلاثمئة منها نحو غيغابايت، وغيغابايت في git يبقى في كل استنساخ إلى الأبد. فالمستودع يحمل **الفهرس والحقيقة**، وهما ما تُراجَع، وتعيش البايتات في مجلد يشير إليه `TRANSFERCHECKER_GOLDEN_ROOT`.

**والذي يجعل هذا آمناً هو SHA-256 في `manifest.json`:** لقطة استُبدلت أو أُعيد تصديرها بجودة أخرى أو دارت بلا قصد لم تعد تطابق بصمتها، والقارئ يسمّيها بالاسم بدل أن يصحّح صورة غير التي قُرئت منها الحقيقة.

## كيف تُدخَل لقطة

```
pnpm --filter @transferchecker/core-omr import-shot \
  --paper 2026-08-20-hp-a4-01 --template standard50 \
  --device 'Pixel 8a' --lighting daylight --angle flat \
  --printer 'HP M404' --pen 'HB' --captured 2026-08-20 \
  --why 'الحالة الاعتيادية' IMG_0031.jpg IMG_0032.jpg IMG_0033.jpg
```

ثم **تُقرأ الورقة بالعين** ويُملأ `truth.json`: كل سؤال `unread` حتى يمسحه إنسان، **والورقة الحقيقية تحتاج اسمين في `readBy`** قبل أن تُحسب في تسليح بوابة الدقة.
