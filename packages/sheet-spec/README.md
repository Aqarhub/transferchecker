# @transferchecker/sheet-spec

مواصفة ورقة الإجابة ومحرك التخطيط والكود المطبوع. **حزمة TypeScript خالصة بتبعيتي وقت تشغيل فقط (Zod ومولّد الـQR)، ولا تعرف شيئاً عن React أو الكاميرا.**

هذه الحزمة هي مصدر الحقيقة الوحيد لمواقع كل شيء على الورقة. مولّد PDF يرسم ما تعيده، والماسح يقرأ من نفس الإحداثيات، فلا يمكن أن يختلفا.

## الاستخدام

```ts
import { SheetSpecSchema, layoutSheet, bubbleGroups } from '@transferchecker/sheet-spec';

const spec = SheetSpecSchema.parse(input);
const result = layoutSheet(spec);

if (result.kind === 'overflow') {
  // Not an error: data the UI turns into guidance for the teacher.
  console.log(result.area, result.axis, result.neededMm, result.availableMm);
} else {
  const groups = bubbleGroups(result.layout); // what the scanner scores
}
```

## المفاهيم

- **`layoutSheet(spec)`** دالة خالصة تحوّل المواصفة إلى إحداثيات بالمليمتر. لا ترمي استثناءً لأي تركيبة قد يطلبها معلم، بل تعيد `overflow` كبيانات.
- **`bubbleGroups(layout)`** تسطّح التخطيط إلى مجموعات، والمجموعة هي فقاعات يُظلَّل منها واحدة على الأكثر (سؤال واحد، أو خانة واحدة من شبكة). الماسح يمشي على المجموعات دون أن يعرف نوع الحقل، فيبقى كود القراءة بلا حالات خاصة.
- **كل فقاعة تحمل رمزها** (`A` أو `٣` أو `أ`)، فالماسح يعيد الإجابة مباشرة.

## الورقة المكتفية بذاتها

الكود المطبوع يحمل **هندسة الورقة كاملة**، لا معرّفها فقط. جهاز لم يرَ القالب قط يقرأ الكود، ويعيد بناء الهندسة، ويصحح الورقة: بلا شبكة، وبلا حساب، وبلا أن يشاركه أحد شيئاً.

```ts
const decoded = decodeSheetCode(layout.code.payload);
if (decoded?.mode === 'full') {
  const groups = bubbleGroups(layoutOrThrow(decoded.spec)); // نفس المواضع تماماً
}
```

- **`code: 'full'`** هو الافتراضي، وهو الأصح لمنتج يعمل أوفلاين أولاً.
- **`code: 'short'`** يحمل المعرّف وحده. الكود أصغر على الورق، والورقة تُقرأ فقط على جهاز يملك القالب. الخيار للمعلم لأن المقايضة حقيقية.

الفارق المقيس على الورقة المرجعية (40 سؤالاً، خمسة خيارات، شبكة معرّف، شبكة نموذج):

| الوضع   | البايتات | الحروف | الوحدات | الحجم المطبوع |
| ------- | -------- | ------ | ------- | ------------- |
| `full`  | 34       | 55     | 29      | 18.5mm        |
| `short` | 17       | 28     | 25      | 16.5mm        |

**مليمتران من الورق ثمن ألا تحتاج الورقة أحداً.**

ما لا يحمله الكود: الأسماء والتسميات والعلامة التجارية. كلها نصوص مطبوعة لا تحرّك فقاعة، وحذفها هو معظم سبب بقاء الكود صغيراً. أما `usage` فمحمول، لأنه ما يتصرف الماسح بناءً عليه.

## قواعد لا تُخالف

1. **الإحداثيات كلها بالمليمتر** والأصل الزاوية العليا اليسرى، وهو نفس اتجاه الصورة بعد تصحيح المنظور.
2. **تغيير ثوابت `GEOMETRY` يكسر التوافق.** ورقة طُبعت اليوم يجب أن تُقرأ بعد سنوات، فأي تعديل يستوجب رفع `SheetSpec.version`.
3. **صيغة الكود جزء من المطبوع أيضاً.** أرقام مجموعات الرموز وترتيب الحقول لا يُعاد ترقيمها أبداً، وأي تغيير يعني `CODE_FORMAT` جديداً لا تعديلاً على القديم.
4. **صفر استيراد من `apps/`.**
