# سجل التطوير (DEVLOG)

> **قاعدة إلزامية:** أي تعديل أو تطوير أو قرار تقني في هذا المشروع يجب توثيقه هنا قبل دمجه.
> كل إدخال يتبع النموذج أدناه، والأحدث يُكتب في الأعلى.

## نموذج الإدخال

```markdown
## [YYYY-MM-DD] عنوان مختصر للتغيير
- **النوع:** إضافة / تعديل / إصلاح / قرار تقني / أمان / توثيق
- **الوصف:** ماذا تغيّر ولماذا.
- **الملفات المتأثرة:** قائمة المسارات.
- **القرارات:** أي قرار تقني اتُّخذ ولماذا، والبدائل المرفوضة.
- **المراجع:** روابط أو مصادر إن وجدت.
```
