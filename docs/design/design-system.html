القواعد التي تمنع الحروف المتقطعة

ثلاثة أسباب تقنية تجعل العربية تظهر حروفاً مفككة على بعض الأجهزة. كلها ناتجة عن إعداد الخطوط لا عن الخط نفسه: 

# 1. Never split a joining script across subset files.
#    Half a word from file A and half from file B cannot be joined.
#    Arabic ships as ONE file. Devanagari ships as ONE file.

# 2. Never subset without keeping the OpenType layout tables.
#    Default settings drop GSUB, which is what picks the initial,
#    medial, final and isolated form of every Arabic letter.
pyftsubset IBMPlexSansArabic-Regular.ttf \
  --unicodes="U+0600-06FF,U+0750-077F,U+08A0-08FF,U+FB50-FDFF,U+FE70-FEFF" \
  --layout-features='*' \
  --flavor=woff2 --output-file=plex-ar-400.woff2

# 3. Never subset to the characters on the page. Student names and
#    exam titles arrive at runtime. Subset by script block only.

# And every stack ends in a system font that has the script, so a
# failed download degrades to correct shaping instead of tofu:
--font-ar: 'IBM Plex Sans Arabic', 'Geeza Pro', 'Noto Naskh Arabic', sans-serif;

الاستضافة ذاتية على نفس النطاق (تقسيم الكاش بين المواقع ألغى فائدة الـCDN المشترك، فلم يبقَ منه إلا جولة اتصال تعطّل العرض)، وWOFF2 فقط، ووزنان لا أكثر، وpreload لملفين فقط، والصينية كسولة على مساراتها وحدها لأن حجمها بالميغابايتات.

العنصر المميز: الورقة تظهر مائلة كما تُصوَّر فعلاً، ثم تلتقطها الأقواس، ثم تستوي (تصحيح المنظور الذي يفعله المحرك حقاً)، ثم تُظلَّل الفقاعات، ثم تصعد الدرجة. هذه اللحظة وحدها هي كل الحركة في الصفحة.

ترتيب الأقسام

  1. المقدمة. لحظة المسح، عنوان واحد، فعل واحد.
  2. كيف يعمل. ثلاث خطوات مرقّمة، والترقيم صحيح هنا لأن المحتوى تسلسل فعلي.
  3. الدقة. أرقامنا المقاسة على المجموعة الذهبية بمنهجيتها.
  4. التخصيص. بناء نموذج الإجابة.
  5. بلا إنترنت وبلا رفع صور. المعالجة على الجهاز.
  6. الأسعار.
  7. الأسئلة الشائعة. عناوين على شكل أسئلة بإجابة مباشرة تحتها.
  8. الخاتمة. الدعوة الثانية والأخيرة للإجراء.

زر الدعوة للإجراء يظهر مرتين فقط: في المقدمة وفي الخاتمة. تكراره في كل قسم يُفقده معناه.

06 القواعد

قاعدة ١
الدوائر للفقاعات وحدها

كل عنصر آخر مستطيل. الدائرة في الواجهة تعني «هذه فقاعة إجابة» ولا شيء غيرها.

قاعدة ٢
ثلاثة ألوان محجوزة

الأخضر والأحمر والكهرماني لا تظهر إلا في نتيجة تصحيح. زر أخضر واحد يربك المعلم لحظة قراءة الدرجة.

قاعدة ٣
الأرقام أحادية المسافة

الدرجات والمعرّفات بخط Mono وأرقام جدولية، فتتحاذى الأعمدة وتُقرأ بالمسح لا بالقراءة.

قاعدة ٤
لحظة حركة واحدة

تسلسل المسح في الهبوط، وصعود بطاقة الدرجة في التطبيق. ما عداهما ساكن.

قاعدة ٥
لا إطار رمادي حول كل شيء

الفصل يجيء من فرق الخلفية: لؤلؤي مقابل أبيض.

قاعدة ٦
العربية أولاً

ارتفاع سطر ١٫٧٥ وحد أدنى ١٦ بكسل. بلا تباعد أحرف ولا مائل ولا أحرف كبيرة.

قاعدة ٧
عائلة خطوط واحدة لكل اللغات

ولا تُجزَّأ الخطوط المتصلة الحروف على ملفات، ولا تُحذف جداول GSUB، وإلا تقطّعت الحروف.

قاعدة ٨
تنقل بمستوى واحد

لا قوائم متداخلة، وموضع التنقل ثابت في كل الصفحات.

قاعدة ٩
فعل أساسي واحد لكل شاشة

والدعوة للإجراء مرتان في الهبوط: المقدمة والخاتمة، لا في كل قسم.

قاعدة ١٠
علامة استفهام لكل زر وقسم

جملة واحدة تقول ماذا يفعل. بلا فلسفة، وبلا شرح داخل نص القسم.

قاعدة ١١
الخلفية لؤلؤية

والبطاقات بيضاء نقية. لا خلفية كريمية.

قاعدة ١٢
مساحة لمس ٤٤ بكسل

ولو صغرت الأيقونة تُوسَّع منطقة اللمس، وحلقة التركيز مرئية دائماً.
